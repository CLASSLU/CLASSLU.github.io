# Engineering Archive Redesign

## Goal

Replace the generic neon technology landing page with a personal engineer work archive that foregrounds the person, real working evidence, and three selected projects.

## Visual Direction

- Warm drafting-paper background, charcoal typography, one vermilion-red accent.
- A portrait illustration anchors the hero; a real work scene and technical detail image establish evidence later in the page.
- Thin grid lines, route nodes, a restrained one-second pointer trail, and a fixed section rail provide the interaction language.
- Dark mode changes paper and ink values without changing the information structure.

## Information Architecture

1. Hero: personal positioning and portrait.
2. Profile: personal working principles and a real work scene.
3. Engineering route: build, connect, run, iterate.
4. Selected projects: local-cloud-hub, codex-proxy, and newXiangQi.
5. Build log and direct contact.

## Resilience

All primary content is static HTML. JavaScript only enhances navigation, theme preference, reveal transitions, section progress, and the pointer trail; a failed script leaves the archive readable.
